Someone breaks into your website at 3 a.m. OODA-Aegis has fixed it before you wake up

An AI agent by Nikhil Kumar. It spots the break-in, blocks it in seconds, writes the code fix, proves the fix works and puts it live. It runs on Meta’s open models, on your own computer.

See it work Open the live dashboard

A website is a door that answers questions

You ask it for a file and it hands you the file. Ask in a sneaky way, with something like ../../etc/passwd, and a website with a bug hands over files it should never share.

Passwords, customer lists, secret keys. The attacker doesn’t need a login. They only need to ask the right wrong question.

Fixing it takes people hours

Someone has to wake up, find the bug, write a fix, test it and ship it. The attacker keeps going the whole time.

A quick blocking rule helps for a minute, until the attacker changes one character. And a fix written by AI is not safe just because it looks right.

OODA-Aegis watches, blocks and fixes on its own

It watches every reply

If a reply contains a system file, another customer’s data, or the site freezes, the agent knows.

It blocks the attack in about 5 seconds

Llama 3.2 3B names the attack and writes a rule for the front door. The agent checks that real customers still get through, then switches it on.

It attacks itself

It invents new versions of the attack to find what the rule misses. It always misses some, so the code has to change.

It never trusts its own fix

Llama 3.1 8B rewrites the broken code. Then the new code goes into a sealed box with no internet.

The real attack must break the old code and fail on the new one. So must every version it invented. And real customers must get exactly the same answers as before. If the AI’s own test says “fine”, that counts for nothing.

Then it goes live with no downtime

The new version gets 10% of visitors, then 50%, then everyone, with checks at every step.

If anything looks wrong, it switches back on its own. If no fix passes the box, it changes nothing and calls a person.

Run it yourself

You need Docker and Ollama. Open localhost:3030, pick an attack and fire it. There is no defend button.

ollama pull llama3.2:3b
ollama pull llama3.1:8b
cd infrastructure
docker compose up --build -d

What is real

In live mode, everything: the website and its leaks, Nginx, Redis, the peer servers, the sealed Docker box, the image builds, the traffic shifts, the switch back and every model call. The dashboard on this site replays runs recorded from that system. The customer records and leaked secrets are fake, and the three bugs were written for the demo.
